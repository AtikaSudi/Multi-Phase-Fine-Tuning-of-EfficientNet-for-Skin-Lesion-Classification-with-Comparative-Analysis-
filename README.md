# Multi-Phase-Fine-Tuning-of-EfficientNet-for-Skin-Lesion-Classification-with-Comparative-Analysis
# **Model Architecture and Training Framework**

**EfficientNet-B0 Backbone:** Pre-trained convolutional neural network used as the core feature extractor for 7-class lesion classification[1][2].
**Label Encoding:** Diagnostic categories mapped directly to integer indices for multi-class classification[2].


# **Dataset and Platform**

**Skin Cancer MNIST (HAM10000):** 2.9 GB medical imaging dataset containing 7 skin lesion diagnostic categories hosted on Kaggle.
